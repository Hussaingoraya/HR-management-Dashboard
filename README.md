# 🚀 MERN Stack Employee Management & Auth System

A full-stack web application built with **React, Node.js, Express, and MongoDB**, featuring secure user authentication (JWT), protected routes, and an intuitive dashboard.

---

## ✨ Features

* **User Authentication:** Secure Signup & Login with JWT (JSON Web Tokens) and bcrypt password hashing.
* **Protected Routes:** React Router setup ensuring unauthorized users cannot access the dashboard or employee pages.
* **Conditional UI:** Dynamic Navbar and forms based on user authentication state.
* **CRUD Operations:** Manage employee records (Add, Edit, View, Delete).
* **UI/UX:** Styled using **Material-UI (MUI)** with success/error toast notifications (`react-toastify`).

---

## 🛠️ Tech Stack

### **Frontend:**
* React.js (Vite)
* Material-UI (MUI)
* React Router DOM
* Axios
* React Toastify

### **Backend:**
* Node.js
* Express.js
* MongoDB & Mongoose
* JWT (Authentication)
* Bcryptjs (Password Hashing)
